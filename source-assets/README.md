# source-assets

Originais (PNG/JPG de alta resolução) usados para gerar os `.webp` de `public/`. **Não são publicados**: ficam fora de `public/` para não irem para o deploy (eram ~50 MB a mais).

Para trocar uma imagem de projeto: converta o original para `.webp` (largura 1200, qualidade ~80) e salve em `public/projetos/`.
